Команды с `--output` требуют нового файла или каталога; расчётные серии не перезаписывают прежние результаты. Скрипты сводок записывают собственные производные таблицы из сохранённых входов. Имена команд взяты из [инструкции воспроизведения](REPRODUCE.md) и связанных расчётных протоколов. Для длительных серий используйте их полные последовательности, настройки и ожидаемые хеши. Для просмотра таблиц достаточно сохранённых JSON и CSV; повторное обучение для чтения результатов не требуется.

Географический зарплатный вариант имеет [отдельный исследовательский пакет](../reports/continuous-core-2026-10-06/research/). Локально проверена арифметика копий; новое обучение в пакете интеграции не повторялось. Этот вариант не включён в расходную модель.

Для 2025 численного экономического результата нет. [Готовность процедуры](../reports/future-outcome-2026-10-04/README.md) и [метод](FUTURE_OUTCOME_VALIDATION.md) описывают отложенный этап; они не подтверждают качество на будущих исходах.
