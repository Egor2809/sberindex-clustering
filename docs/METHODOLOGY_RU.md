# Группы потребления: методика

Короткое приложение к [отчёту](REPORT_RU.md): слои графа, методы, правила выбора, оценка вне времени и динамика. Все числа взяты из файлов в `reports/`.

## 1. Данные и признаки

Источник данных: СберИндекс, средние безналичные расходы жителей по пяти категориям и общему показателю. Полная история за 24 месяца 2023–2024 годов есть у 2 016 МО в 73 регионах; неполные ряды исключены, пропуски нулями не заменяются. Ключ записи: `territory_id`. Все МО имеют одинаковый вес. [Происхождение данных](DATA_SOURCES.md).

Для категории c ∈ {здоровье, маркетплейсы, общепит, продовольствие, транспорт}, МО i и месяца t:

```text
r_itc = log(E_itc / E_it,total)
x_itc = (r_itc − median_2023(r_c)) / (IQR_2023(r_c) · √5)
```

Медиана и IQR взяты по 2023 году и заморожены для 2024 года. Уровень расходов в расстояние не входит. Годовой профиль равен покомпонентной медиане двенадцати месячных векторов.

## 2. Слои графа

Каждое МО выбирает k = 15 ближайших. Ребро есть, если j ∈ N_k(i) или i ∈ N_k(j). Для расстояния вес задаёт гауссово ядро exp(−d² / 2σ²), где σ равна медиане расстояний до k ближайших; для сходства весом служит само сходство при s > 0.

| Правило | Определение | Где используется |
|---|---|---|
| `euclid_profile` | ‖x_i − x_j‖ профилей (годовых или месячных), σ = 0,188 для годового | слой P, помесячный признаковый слой |
| `cosine_shares` | косинус векторов долей | только сравнение |
| `pearson_series` | средняя корреляция шести остаточных рядов | только сравнение |
| `lagged_correlation` | то же, максимум по сдвигам ℓ ∈ {−3,…,3} | слой C годового каркаса |
| `dtw_series` | многомерный DTW, полоса 2 месяца | только сравнение |
| `road_distance` | расстояние по автодорогам на 31.12.2024, σ = 98,7 км | помесячный дорожный слой; внешняя проверка каркаса |

Остаточные ряды: из log E_itq вычитается медиана месяца по стране, затем ряд каждого МО центрируется и нормируется. Так остаётся только форма колебаний. Конфигурация лежит в `configs/edge_rules.json`, сравнение в [reports/edge-rules](../reports/edge-rules/).

Слои складываются после нормировки на сумму весов: G = α·P + (1−α)·C для годового каркаса и G_t = 0,5·A_t + 0,5·R для месяца t (A_t: признаковый kNN месяца, R: дороги).

## 3. Методы

**Годовой каркас** (`sbercluster/network_core.py`, `configs/network_core.json`). Leiden с функцией качества RBConfiguration на G:

```text
Q_γ = Σ_ij [A_ij − γ · k_i k_j / (2m)] · δ(c_i, c_j)
```

Сетка α ∈ {0; 0,25; 0,5; 0,75; 1}, γ ∈ {0,1; 0,2; 0,3; 0,5; 0,75; 1}, 20 seed. Группы меньше 20 МО присоединяются к соседу с наибольшим весом рёбер. Итогом варианта служит медоид, то есть запуск с наибольшим средним ARI к остальным 19.

**Временной Leiden.** Месячные графы G_1…G_24 связаны рёбрами между одним и тем же МО в соседних месяцах:

```text
Q = Σ_t Q_γ(G_t, c^t) + ω · Σ_t Σ_i δ(c_i^t, c_i^{t+1}),   γ = 0,7
ω = ω_rel · медианная взвешенная степень вершин 2023 года,   ω_rel ∈ {0; 0,01; 0,03; 0,06; 0,1}
```

Три seed (1729, 2718, 3141), четыре итерации Leiden. Число групп метод выбирает сам.

**Базовые линии.** KMeans4 по годовому профилю 2023 года (seed 1729, n_init = 20): центры 2023 года для всех месяцев (с сезонной поправкой и без) и KMeans4 заново каждый месяц. Спектральная кластеризация K = 3 на том же G, Leiden по одному слою P или C. Прежние сравнения (Ward, GMM, совместная модель «расходы + дороги», DMoN) описаны в [ROUND2_RESULTS.md](ROUND2_RESULTS.md) и [DMON_REFERENCE.md](DMON_REFERENCE.md).

## 4. Правила выбора

Правило ω появилось в конфиге вместе с результатами 2 октября, когда ω = 0,01 уже использовался в первой серии; правило его подтверждает. Правило годового каркаса 7 октября переведено на метрики 2023 года и выбирает тот же вариант, что и первая версия по 2024 году.

**Годовой каркас.** Вариант допустим, если средний ARI между seed ≥ 0,8, минимальная группа ≥ 20 МО и групп от 3 до 12. Среди допустимых строится парето-фронт по (SW-2023, MQ на C-2023). Из фронта берётся максимум суммы рангов шести индексов 2023 года. Сетевые индексы входят с половинным весом на P-2023 и на C-2023, дорожный граф и данные 2024 года в выборе не участвуют. Итог: α = 0,75, γ = 0,3, K = 3, устойчивость 0,804.

**ω.** Берётся наибольшее ω_rel, при котором средняя MQ среза (по 24 месяцам и трём seed, на признаковом графе месяца) не ниже 98 % от MQ при ω = 0. Итог: ω_rel = 0,01. На смешанном графе то же правило дало бы 0,1.

**KMeans4.** Формальное правило выбора K на сетке 2…8 (устойчивость по бутстрепу и seed, локальные оптимумы индексов) даёт K = 2, gap statistic даёт K = 5, поэтому K = 4 остаётся выбором по интерпретации ([расчёт](../reports/robustness/)).

## 5. Оценка вне времени

Индексы определены в [METRICS.md](METRICS.md). SW, CH и S_Dbw считаются на признаках, AVI, AVU и MQ на бинарном графе.

**Годовой каркас.** Разбиение 2023 года оценивается на признаках и графах 2024 года, построенных теми же правилами: SW, CH, S_Dbw на профиле 2024 года, AVI, AVU, MQ на P-2024, C-2024 и R. Тот же метод заново запускается на 2024 году, и его разбиение сравнивается с разбиением 2023 года по ARI.

**Помесячные разбиения** (`sbercluster/temporal_quality.py`, `configs/temporal_quality.json`). Для каждого месяца t:

- SW, CH, S_Dbw на признаках месяца t; AVI, AVU, MQ на признаковом kNN-графе месяца t;
- MQ_mix: MQ на смешанном графе G_t, на котором учился временной Leiden;
- MQ_next, AVI_next: разбиение месяца t на графе месяца t+1; отношение MQ_next к MQ собственного разбиения месяца t+1 показывает, переносится ли структура;
- ARI соседних месяцев и доля МО, сменивших группу; ARI одних и тех же месяцев между seed.

## 6. Динамика

**События групп** (Greene, Doyle, Cunningham, 2010). Для групп C (месяц t) и D (месяц t + 1) J(C, D) = |C ∩ D| / |C ∪ D|; пара связана, если J ≥ 0,3.

| Связи | Событие |
|---|---|
| один-к-одному, \|D\| / \|C\| > 1,1 | рост |
| один-к-одному, \|D\| / \|C\| < 0,9 | сокращение |
| один-к-одному, иначе | продолжение |
| одна группа связана с несколькими | распад |
| несколько групп связаны с одной | слияние |
| у новой группы нет пары | рождение |
| у старой группы нет пары | исчезновение |

Группа ведётся по цепочке событий. Группа, которая пропала и вернулась с Жаккаром ≥ 0,5, считается той же. Устойчивая группа живёт не меньше 6 месяцев (`scripts/describe_temporal_groups.py`).

**Сезонная поправка** для фиксированных центров строится классической декомпозицией медиан признаков:

```text
M_tc = median_i x_itc;   T_tc: центрированная скользящая средняя 2×12
u_mc = mean_{t: месяц t = m} (M_tc − T_tc);   s_mc = u_mc − mean_m u_mc;   x'_itc = x_itc − s_m(t),c
```

**Общий сдвиг.** Чтобы проверить дрейф фиксированных центров, из признаков каждого месяца вычитается сдвиг медианы по всем МО относительно января 2023 года, по одной категории или по всем сразу. Помесячный kNN-граф от такого сдвига не меняется: он зависит только от расстояний между МО в одном месяце.

## 7. Внешняя проверка

Население (Росстат и БД ПМО), зарплата и занятость крупных и средних организаций за 2023 год сопоставлены с МО по ОКТМО. Для каждого разбиения считается прирост R² сверх фиксированных эффектов региона и логарифма населения, интервал строится по 200 бутстрэп-выборкам регионов ([network-core](../reports/network-core/), [external-municipal](../reports/external-municipal/), [type-validation](../reports/type-validation/)).
