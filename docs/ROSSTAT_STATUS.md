# Внешняя проверка по Росстату

Сопоставлены по ОКТМО 11 муниципалитетов Республики Алтай за 2024 год. Использованы отгрузка организаций без субъектов малого предпринимательства и показатели коллективных средств размещения. Исходные ссылки, единицы, SHA-256 и мост идентификаторов доступны в [папке проверки](../reports/external/altai-2024/README.md).

Из 137 строк отраслевой отгрузки 55 содержат числовые значения, 77 закрыты и 5 отсутствуют. Закрытые и отсутствующие величины не заменены нулём. Файл занятости с кодами ОКАТО не присоединён к ОКТМО напрямую.

Проверка показывает пределы отраслевого именования: внутри одного типа резко различается объём ночёвок и отгрузки. Один небольшой регион не подтверждает экономические типы на всей территории страны.

Для расширения проверки нужны сопоставимые муниципальные показатели занятости, зарплат и производства с проверенными кодами, единицами и периодами. Национального соединённого набора этих показателей в текущем выпуске нет. Метод сопоставления нельзя заменять поиском похожего названия территории.
