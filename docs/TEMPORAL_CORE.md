# Как сравнивать потребительские профили во времени

Основной KMeans4 сохраняет исходный замороженный профиль. Рядом можно получить второй профиль: изменение относительно типичного парного изменения фиксированной группы муниципальных записей. Для него нужен зафиксированный пакет текущего месяца. Оба результата сохраняются; у них разные вопросы и разные ограничения.

Исходный профиль показывает положение записи в шкале 2023 года. Относительный профиль показывает её положение после вычитания медианного изменения референса. Общий сдвиг при этом остаётся в пакете поправки и в исходном канале. Алгоритм не определяет, вызван ли он экономикой, изменением состава потребления или методики оценивания.

Числовой контракт реализован и проверен. Подтверждённые переходы территорий не выпускаются: постоянство ID не доказывает постоянство границ. 2024 год уже изучался; все приведённые результаты описывают историческую чувствительность, а не новую независимую проверку. Референс 2016 ID выбран по ретроспективно полной истории 2023–2024.

## Два объекта оценки

Для пяти положительных категорий `C_j` и общего итога `T` применяются сохранённые центр `a_j` и IQR `s_j`2023 года:

```text
x_j = (log(C_j/T) - a_j) / (s_j * sqrt(5)).
```

«Исходный» или «абсолютный» здесь означает положение в этой фиксированной шкале отношений, а не расходы в рублях. Общий множитель у категорий и итога не меняет признаки. Поэтому отдельно сохраняется аудит `log(C_j)` и `log(T)`. Категории не объявлены непересекающимися долями: сумма 1, остаточная категория и композиционное замыкание не добавляются.

Для месяца `m` текущего года и неизменного списка референса `R0`:

```text
delta_i = x_current(i,m) - x_2023(i,m)
g_m = coordinate_median(delta_i for i in R0)
A_i = coordinate_median(x_current(i,m), m=1..12)
R_i = coordinate_median(x_current(i,m) - g_m, m=1..12)
```

Парная медиана изменений отличается от разности популяционных медиан. Например, для базовых значений `(0,10,11)` и текущих `(9,10,20)` первая равна 9, вторая 0. Прежняя поправка разностью медиан сохранена как отдельная диагностика. По улучшению ARI нельзя выбирать между этими определениями относительности.

Поправка применяется к каждому месяцу до годовой медианы. В общем случае `median(x-g)` отличается от `median(x)-median(g)`. В годовом экспорте сохраняется `effective_removed=A-R`; этот вектор может различаться у территорий при одинаковых месячных поправках.

Получение `g_m` трансдуктивно: оно использует текущие референсные записи. Применение уже опубликованного пакета к отдельной записи детерминировано и не зависит от других запросов. Новый муниципальный ID не входит в референс автоматически и получает `new_entity=true`; без базовой пары ему не приписывается индивидуальный переход.

## Фиксированный референс, пропуски и отказ

Базовый артефакт сохраняет исходную модель, порядок категорий, двенадцать базовых признаков каждого ID, регионы и происхождение состава. Его создают только из полного календарного 2023 года. Будущие значения не участвуют в построении. Историческое происхождение состава указывается отдельно и не становится проспективным от этого ограничения.

Каждый месячный пакет содержит хеш референса, календарный месяц, парные изменения, полный знаменатель покрытия и покрытие каждого базового региона. Ключи сопоставляются по ID. Конфликтующие дубли останавливают создание пакета. Отсутствующие и неположительные/нечисловые референсные оценки остаются в знаменателе; они не заменяются нулями и не удаляются из состава референса.

При `q` пропущенных пар точные координатные границы медианы полного референса имеют вид:

```text
L = median(observed_deltas plus q values -infinity)
U = median(observed_deltas plus q values +infinity)
```

Они не предполагают случайность пропусков. Полная парная медиана записывается отдельно только при полном наблюдении. Для частичного состава сохраняются границы и, если они конечны, их середина как вычислительный представитель. Медиана доступных пар служит отдельной диагностика. Бесконечные границы в JSON представлены `null` и явными флагами неограниченности.

Для заданной записи относительный прямоугольник равен `[x-U,x-L]`. Годовые границы получают медианой двенадцати нижних и двенадцати верхних границ. Метка представителя вычисляется от медианы месячных представителей; середина годового прямоугольника её не заменяет.

Пакет другого месяца, повреждённый или структурно неверный пакет и неограниченная поправка дают явный отказ относительного канала. Исходный годовой профиль остаётся доступен при полных корректных данных записи. Неполный календарный год возвращается с `month_mask`, статусом `incomplete_entity_year` и отсутствующей годовой меткой. Последняя доступная поправка на следующий месяц не переносится.

Пакеты привязаны к содержимому SHA256. CLI проверяет хеш точных прочитанных байтов и создаёт выходные файлы эксклюзивно: изменение источника требует нового файла и нового хеша. Хеш связывает байты и не удостоверяет семантическую сопоставимость источника.

## Что означает геометрический сертификат

При неизменных центрах разность квадратов расстояний до двух центров линейна по координатам. Её минимум на прямоугольнике вычисляется по его вершинам без полного перебора. Если минимум для выбранной области строго положителен с фиксированным числовым допуском, `geometric_label` одинаков на всём указанном прямоугольнике. В противном случае сохраняется точечная метка, а геометрическая метка отсутствует с `boundary_ambiguous`.

Текущая реализация относится к точным признакам, `epsilon=0`. Она не оценивает погрешность источника, радиус экономической поддержки или вероятность правильной метки. Полные 2016 исторических записей имеют устойчивую вычислительную область, но число подтверждённых территориальных переходов равно 0; `transition_status=unresolved` сохраняется в каждой записи.

Допуски ошибок, минимальное покрытие и радиусы поддержки требуют отдельного обоснования. Предложенные внешним аналитическим контрактом значения `.02`, 90%/80%, 99%-квантили и 80% эксплуатационной пригодности не введены как требования или измеренные гарантии.

## Что дал конечный эксперимент

Все методы и оба пространства оценивания сохранены в [компактном пакете свидетельств](../reports/temporal-core-2026-10-03/README.md). Оценки SW/CH для сравнения вычислены на общих исходных признаках. Три новые калибровки используют только 2023: календарную поправку и два фиксированных веса метрики временной вариации `.5/1`. Дополнительного поиска после результатов не было.

Календарная калибровка повышает исторический ARI `.559700→.618903`, но минимальная группа 2024 остаётся 27. Две метрики временной вариации ухудшают SW и устойчивость; минимумы 22/23. Все три отклонены по заранее записанному совместному диагностическому критерию: SW не ниже основного более чем на `.005`, CH не ниже 90%, минимальная годовая доля 3% и ARI не ниже основного. Критерий относится только к этому опыту; это не требование конкурса и не гарантия на новых данных. Основной и прежние альтернативные методы также не проходят компонент минимальной доли 2024; этот факт сохранён.

Разложение парного годового перемещения на средний сдвиг и остаток даёт 73.849% суммы квадратов на общем компоненте. Оно геометрическое. 311 смен при добавлении только среднего сдвига и 202 при добавлении только остатка образуют неаддитивные контрфактические множества; они не распределяют 380 наблюдаемых смен по причинам.

Новый парный относительный канал даёт 218 смен, ARI`.722494`, минимальную группу 69 и SW`.270561` в общей геометрии 2024. Прежняя популяционная поправка даёт 207 смен и ARI`.739422`. Эти числа описывают разные нормировки. Основная замороженная модель сохраняет 380 смен и ARI`.559700`; её 2024-метки воспроизведены точно.

В одиннадцати проверках пропусков и удаления крупнейших референсных регионов истинная полная медиана лежит в вычисленных границах. При 50% и 60% пропусков границы неограничены, относительная поправка не выпускается. Показано региональное покрытие с неизменными знаменателями; универсальный порог пригодности не подбирался.

Распределительная диагностика сохраняет квантили и описательную Gaussian MMD² по [Gretton et al.,2012](https://www.jmlr.org/papers/v13/gretton12a.html). Ширина ядра зафиксирована по расстояниям 2023. Значения`.098008` для исходного сдвига и`.002592` для парного относительного канала не имеют заявленного p-value или причинной интерпретации. Перестановка профилей между ID может оставить распределение прежним при ненулевых индивидуальных перемещениях; обе стороны проверены отдельно.

## API и воспроизведение

`sbercluster.dual_profiles` предоставляет `build_reference_lock`, `build_reference_packet` и `predict_dual_panel`. Текущий контракт поддерживает сохранённый K4 в исходном пятикоординатном пространстве с единичными преобразованиями и нулевыми смещениями расстояний. Неподдерживаемый артефакт отклоняется явно. H75 и ordinary остаются прежними отдельными альтернативами и контрольными методами.

Из корня репозитория в среде проекта:

```powershell
# Создать частный базовый артефакт; MODEL_SHA берётся из model-frontier/models/manifest.json
python -m scripts.predict_dual lock --panel data/processed/panel.csv `
  --model reports/model-frontier-2026-10-03/models/historical_kmeans4.json `
  --expected-model-sha256 12e72c67cd6e2db9d3249a9211670eb04336c69fa5883cb5b1a0277496edb334 `
  --output .local/dual-use/reference.json

# Зафиксировать хеш созданного артефакта и выпустить пакет одного месяца
$referenceSha = (Get-FileHash .local/dual-use/reference.json -Algorithm SHA256).Hash.ToLower()
python -m scripts.predict_dual packet --panel data/processed/panel.csv `
  --reference .local/dual-use/reference.json --expected-reference-sha256 $referenceSha `
  --period 2024-01-01 --output .local/dual-use/packets/2024-01-01.json

# Один полный воспроизводимый исторический запуск создаёт все 12 пакетов и их manifest
python -m scripts.benchmark_dual_profiles --output .local/dual-reproduce
$referenceSha = (Get-FileHash .local/dual-reproduce/private-reference-lock.json -Algorithm SHA256).Hash.ToLower()
$packetManifestSha = (Get-FileHash .local/dual-reproduce/packet_manifest.json -Algorithm SHA256).Hash.ToLower()
python -m scripts.predict_dual predict --panel data/processed/panel.csv `
  --reference .local/dual-reproduce/private-reference-lock.json --expected-reference-sha256 $referenceSha `
  --packet-manifest .local/dual-reproduce/packet_manifest.json --expected-packet-manifest-sha256 $packetManifestSha `
  --year 2024 --output .local/dual-reproduce/predictions.json

# Отдельное воспроизведение отрицательных альтернатив; оно действительно обучает 3 модели
python -m scripts.benchmark_temporal_profiles --output .local/temporal-reproduce
python -m unittest discover -s tests -p 'test_dual_profiles.py' -v
python -m unittest discover -s tests -p 'test_temporal_profiles.py' -v
python reports/temporal-core-2026-10-03/source/independent-math-kernel/temporal_core.py --self-test
```

Завершённые вычисления для того же кода и входов повторять не требуется. Публичный пакет содержит числовые результаты, метки, модельные артефакты и снимки исходников. Полная входная панель и базовый помесячный референс остаются отдельными частными артефактами. Для самостоятельного воспроизведения нужны подготовленные исходные данные и тот же контракт идентичности источника.

Проверены 11 тестов временной калибровки и 14 тестов парного метода, включая будущие данные, порядок/состав запросов, ключи источника, пропуски, границы, неизменность пакетов и хеши прочитанных байтов. Независимое математическое ядро отдельно воспроизвело 4915 заполнений пропусков, 8000 вершин прямоугольников и 100 годовых интервальных заполнений. Более широкая предложенная эксплуатационная матрица не объявлена полностью выполненной. Экономическое превосходство нового относительного канала и применимость за пределами исторического состава не установлены.
