# Техническое ядро: подготовка, контракты и замороженная модель

Проверка от 3 октября 2026 года продолжает [предыдущую численную итерацию](../README.md). Исторические результаты сохранены; новые проверки привязаны к исходникам в этом каталоге.

Подготовка данных теперь строит все результаты отдельно и публикует их после проверки источников. При обычной ошибке публикации прежние байты восстанавливаются; при ошибке самого восстановления остаются резервные файлы и блокировка. Изменение любого источника во время подготовки приводит к отказу до публикации. Обязательные идентификаторы проверяются; пропущенные географические координаты допустимы и не используются моделью.

Замороженные центры в исследовательских потребителях связаны с точным архивным SHA-256. Совпадения прежних меток для проверки версии недостаточно. Описание профилей также проверяет совпадение настроек преобразования признаков. Новый API и CLI применяют фиксированную модель к месячным данным и полным годам без обучения; результат содержит модель, исходники, версии зависимостей и хеши.

Статические и временные модели отклоняют несогласованные признаки, графы, идентификаторы, календарь и некорректные настройки. CLI и API одинаково проверяют разрешённую область временного анализа; ошибки и прерывания записываются в статус запуска. Фактическое число занятых кластеров отделено от запрошенного, матрицы переходов строятся для реального числа прототипов.

## Подтверждённые проверки

- **206 тестов прошли**, компиляция модулей и скриптов прошла.
- Чистая копия исходников с тремя сырыми источниками восстановила панель 2 016×24 с точным прежним SHA-256. Готовая панель в копию не переносилась.
- Все **48 384 месячные и 4 032 годовые метки** совпали с архивом. Разница месячных относительных дистанционных отступов — ноль. Обучения в этой проверке не было.
- Отдельно проверены откат записи, сохранение резервных копий при невозможности отката, блокировка второго писателя, изменение источника во время подготовки, подмена модели при прежних метках и несовпадение калибровки признаков.
- Малый реальный запуск временного Leiden прошёл для фиксированных четырёх итераций и режима до отсутствия улучшения (`-1`). Отдельный критический проход не оставил блокирующих замечаний в указанной технической области.
