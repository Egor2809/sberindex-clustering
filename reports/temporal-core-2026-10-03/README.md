# Временной контракт потребительских профилей

Замороженный KMeans4 остаётся основным методом. Три новые калибровки по 2023 не устранили малые группы при применении к 2024; отрицательные результаты сохранены. Новый парный относительный канал показывает изменение относительно фиксированной группы сравнения и сохраняет исходный профиль рядом. У этого канала другой объект оценки; рост ARI не доказывает, что он точнее или экономически лучше.

Подробный контракт и команды: [TEMPORAL_CORE.md](../../docs/TEMPORAL_CORE.md).

Все эти 2024-оценки относятся к уже изученной исторической панели. Референс:2016 ID,73 региона, ретроспективно полная история 2023–2024. Идентичность ID не подтверждает неизменность границ. Подтверждённых территориальных переходов нет.

## Состав свидетельств

- `negative-arms/`: заранее записанный конечный протокол, все три альтернативы, ordinary/H75/K4-контроли,24 месяца/8 кварталов, обе геометрии, сдвиговые проверки и числовые метки.
- `paired-reference/`: один запуск без обучения,12 зафиксированных пакетов поправок, региональное покрытие и 11 проверок пропусков; абсолютные 2024-метки точны. Полный базовый референс с помесячными признаками хранится в частном артефакте; в этом пакете его метаданные и хеш, без копии входной панели.
- `models/`: три явно экспериментальные калибровки. Политика минимума групп при применении отсутствует. `deployment/` проверяет 12,096 точных назначений после добавления только метаданных идентичности источника.
- `validation/`:11 тестов временной калибровки,14 тестов парного контракта, точный CLI roundtrip всех 2016 записей по четырём числовым каналам меток и локальная повторная проверка независимого математического ядра. Полная предложенная внешним исследователем эксплуатационная матрица S01–S20 не объявлена выполненной.
- `source/`: отдельно код исходного числового запуска, парного применения, окончательной реализации и независимое математическое ядро. Последнее проверено локально, но не встроено без изменений: рабочая реализация добавляет ключи/пакеты/покрытие/публичную границу применения.

Общий средний сдвиг объясняет 73.849% суммы квадратов годового перемещения в исходном пространстве признаков. Это геометрическое разложение, не причина изменения. В парном канале описательная MMD² уменьшается 0.098008→0.002592 при ширине ядра, зафиксированной по 2023; статистический уровень значимости не заявлен. MMD используется для сравнения распределений по [Gretton et al.,2012](https://www.jmlr.org/papers/v13/gretton12a.html).

Сертификат относится к заданному точному прямоугольнику признаков при epsilon=0. Все 2016 полных исторических записей имеют устойчивую вычислительную область; это не измеренная устойчивость к ошибкам источника, гарантия будущего покрытия или подтверждение географии. Предложенные допуски epsilon.02, 90%/80% покрытия,99%-радиусы и 80% эксплуатационной пригодности не приняты как факты или требования.

`manifest.json` связывает этот компактный пакет с исходниками.
