# DMoN: продолжение обучения

Шесть вариантов K2/K4 × seeds1729/2718/3141 достигли эмпирического плато за 10 000–16 500 эпох. Правило остановки зафиксировано в [конфигурации](../../configs/dmon_plateau.json); оно использует обучающий loss и стабильность меток, без внешнего показателя.

Для всех шести запусков совпадение меток эпохи 1 000: 6/6. Максимальная абсолютная разница loss первых 1 000 эпох: 3.87e-07. Сборки PyTorch различаются, поэтому побайтное совпадение loss не предполагается. Старые результаты не переписаны.
