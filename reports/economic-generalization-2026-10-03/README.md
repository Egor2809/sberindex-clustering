# Индуктивная экономическая проверка: 2023–2024

Каждый регион исключён из калибровки расходов, обучения KMeans4/H75 и зарплатного предиктора. Полная проверка фиксированной архитектуры: 72 разбиения, 12 предикторов, 1797 МО в 2023; замороженный перенос 2023→2024 — 1678 МО в 68 регионах. Нелинейный предиктор на пяти непрерывных признаках даёт меньшую ошибку уровня зарплаты, чем кластеры. Преимущество H75 над KMeans в этой проверке зависит от семейства предиктора.

Дополнительная проверка трёх отраслевых долей переиспользует те же 72 расходные модели. Все 1797 допустимых МО получают прогнозы, включая отсутствующие исходы. Точные границы потерь при любой недостающей доле в [0,1] включают ноль во всех 36 направленных сравнениях: преимущество по полной целевой совокупности не установлено. Цель ограничена доступностью обязательных контролей; это не вывод для всех 2016 МО.

[Метод, все таблицы, ограничения и команды](../../docs/ECONOMIC_GENERALIZATION.md).

## Состав

- `wage/`: исходный протокол, все OOF-прогнозы, 72 калибровки/правила назначения/признаки/метки и параметры зарплатных моделей, версии, исходный расчётный код.
- `sectors/`: протокол до обучения исходов, все прогнозы полной допустимой совокупности, наблюдаемые ошибки, точные границы, 216 наборов параметров для 864 предикторов.
- `context/forecast-context.json`: отдельное сравнение с прошлой зарплатой самого МО; это дополнительная информация, которую расходные модели не получают.
- `acceptance/`: независимые проверки чисел/разбиений/крайних заполнений/покрытия населения и собственные тесты. Оракулы сохранены как точные исходные снимки проведённой приёмки; их первоначальные пути расчёта указаны в коде.
- `launch-fix.json`: привязка изменения только запуска после расчёта; научные AST сохранены. Реальный Linux-расчёт не заявляется.
- `manifest.json`: полный список размеров и SHA-256, входные и исходные привязки. Исходные архивы и прежний национальный пакет не дублированы.

Воспроизведение выполняется из корня репозитория в **новый** каталог, на входах с хешами из протокола:

```powershell
python -m scripts.validate_economic_generalization --output runs/economic-generalization-reproduced --include-h75
python -m scripts.validate_economic_sector_generalization --expense-folds runs/economic-generalization-reproduced --output runs/sector-generalization-reproduced
python -m unittest discover -s tests -p "test_economic*.py" -v
```
