# Возвраты в группу на реальных данных

Правило записано до запуска (текст в `summary.json`, поле `rule`): временной Leiden выигрывает, если у него меньше возвратов на одно МО, чем у каждого варианта KMeans. Возврат: МО уходит из группы и возвращается в неё не позже чем через три месяца.

```sh
.venv/bin/python scripts/temporal_stability.py
```

| Метод | Смен группы на МО | Возвратов на МО | Доля возвратов среди смен | МО, менявших группу |
|---|---:|---:|---:|---:|
| Временной Leiden | 2,99 | 1,47 | 49 % | 1 125 |
| KMeans4, заново каждый месяц | 3,69 | 1,81 | 49 % | 1 645 |
| KMeans7, заново каждый месяц | 5,35 | 2,94 | 55 % | 1 537 |
| KMeans4, центры 2023 года, с сезонной поправкой | 1,34 | 0,63 | 47 % | 970 |
| KMeans4, центры 2023 года, без поправки | 2,08 | 0,88 | 42 % | 1 200 |

По правилу Leiden не выигрывает. Он стабильнее KMeans, который каждый месяц обучается заново, но фиксированные центры KMeans4 дают меньше смен и возвратов. Почти половина смен у всех методов возвращается в прежнюю группу за три месяца: границы между группами районов размыты.
